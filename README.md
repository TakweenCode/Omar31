# عمر يحتفل بيوم الطفل العالمي 🎈

تطبيق ويب تفاعلي للاحتفال **بيوم الطفل العالمي (20 نوفمبر)** — يجمع بين بالونات الأمنيات التفاعلية، ولوحة الأحلام المستقبلية، واستوديو الرسم وتصميم بطاقة التهنئة عالية الدقة.

- **مشاركة الطالب:** عمر
- **إشراف:** المعلمة نورة الحصيني
- **الروضة:** الروضة 31

## المميزات
- **بالونات الأمنيات التفاعلية:** تفجير البالونات مع مؤثرات بصرية وصوتية لطيفة لقراءة أمنيات عمر.
- **لوحة الأحلام (ماذا أحلم أن أكون؟):** اختيار الحلم المستقبلي وإضافته مباشرة إلى بطاقة التهنئة.
- **استوديو الرسم والبطاقة:** لوحة رسم لمسية بالفرشاة والأختام والألوان والممحاة والتراجع، مع توليد بطاقة تهنئة PNG جاهزة للحفظ والمشاركة (`1080×1350`).
- **خصوصية تامة:** جميع الرسومات والأسماء تُعالج داخل جهاز المستخدم فقط دون إرسال أي بيانات لأي خادم.

## طريقة النشر على GitHub Pages
1. ارفع جميع ملفات المشروع (بما فيها مجلد `.github/workflows/deploy.yml`) إلى مستودعك على **GitHub** على الفرع الرئيسي `main`.
2. من إعدادات المستودع انتقل إلى **Settings ← Pages**.
3. تحت **Build and deployment** اختر **Source: GitHub Actions** (مهم: لا تختر *Deploy from a branch* لأن المتصفح سيقرأ ملف `src/main.tsx` الخام ويعطي خطأ 404).
4. بعد اكتمال تشغيل الـ Workflow في تبويب **Actions**، سيُنشر التطبيق تلقائياً على رابط `https://<username>.github.io/<repo-name>/`.
